# Shri Panchanan Pvt Ltd — Upgraded App

## Included
- Professional mobile-first storefront
- Product search and categories
- Add to Cart / quantity controls
- Checkout with delivery address
- Cash on Delivery and UPI/advance-payment preference
- Local order history
- WhatsApp order handoff
- PWA manifest + service worker
- Responsive design for Android phones

## Important before live payments
The UPI/Advance option currently records the customer's payment preference and sends the order to WhatsApp. It does **not** process or verify a real payment.

For real online payments, connect a verified payment gateway (for example Razorpay/PayU) with a secure backend before taking live customer payments.
