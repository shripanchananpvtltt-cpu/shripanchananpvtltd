SHRI PANCHANAN PVT LTD — V4
================================
Files:
- index.html
- style.css
- script.js

How to publish on GitHub Pages:
1. Extract this ZIP.
2. Open your GitHub repository.
3. Replace the old index.html, style.css and script.js with these files.
4. Commit changes.
5. Open GitHub Pages / your existing website.

Important:
- Cart and My Orders use browser localStorage, so they work on the same device/browser.
- UPI is only a payment preference in this version. A verified payment gateway is required for live online payments.
- WhatsApp button uses the business number already shown on your website.
